Design the filter system for a map-based interdisciplinary healthcare collaboration platform. This is the second half of the experience after onboarding has already been completed. Focus only on the filter layer, side panel, floating chips, and map-adjacent controls that let users refine collaborator results.

The platform supports three user groups:

* Doctors / Clinicians
* Engineers
* Designers

The filter system should feel accessible across all three groups. It should use shared categories with role-specific suggested tags, so the interface feels unified rather than siloed. The design should make filtering feel intuitive, editable, and dynamic, with the map acting as a live reference point for all selected criteria.

UI direction:

* Design this as a modern map filter system with a side panel and floating filter chips
* The map is the main canvas, but the filters are always visible and editable
* Show selected filters as removable chips
* Organize filters in collapsible groups
* Let users switch between shared tags and role-specific suggested tags
* Include an exact match vs adjacent match toggle
* Include a radius or proximity control
* Include an option to broaden or narrow semantic matching
* Include collaborator result cards tied to map pins
* Let the user refine filters without losing map context
* Keep the information architecture clean, approachable, and cross-disciplinary
